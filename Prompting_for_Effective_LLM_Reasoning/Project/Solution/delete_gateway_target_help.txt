delete_gateway_target(*args, **kwargs) method of botocore.client.BedrockAgentCoreControl instance
    Deletes a gateway target.



    You cannot delete a target that is in a pending authorization state ( ``CREATE_PENDING_AUTH``, ``UPDATE_PENDING_AUTH``, or ``SYNCHRONIZE_PENDING_AUTH``). Wait for the authorization to complete or fail before deleting the target.



    See also: `AWS API Documentation <https://docs.aws.amazon.com/goto/WebAPI/bedrock-agentcore-control-2023-06-05/DeleteGatewayTarget>`_


    **Request Syntax**
    ::

      response = client.delete_gateway_target(
          gatewayIdentifier='string',
          targetId='string'
      )

    :type gatewayIdentifier: string
    :param gatewayIdentifier: **[REQUIRED]**

      The unique identifier of the gateway associated with the target.




    :type targetId: string
    :param targetId: **[REQUIRED]**

      The unique identifier of the gateway target to delete.





    :rtype: dict
    :returns:

      **Response Syntax**


      ::

        {
            'gatewayArn': 'string',

            'statusReasons': [
                'string',
            ]
        }
